Sometimes the image you want is trapped inside another image — surrounded by app chrome, blurred backgrounds, and awkward edges.

→ Inlay is made for that.
01 / What it does

Find the foreground.
Leave the rest behind.

Inlay analyzes a screenshot, looks for a prominent image region, and exports the crop as a PNG.

⌗

Detects the image

Uses image geometry, edges, and visual sharpness to rank likely foreground regions.

◩

Keeps the edges

Can preserve rounded corners with transparent edges, instead of baking the blurred background into the crop.

⇥

Handles batches

Process a folder of screenshots, optionally including subfolders, from one command.

⌖

Knows when to stop

Uncertain detections are marked for review rather than silently exported as confident results.

02 / Getting started

Fits into
your workflow.

Inlay is a command-line utility. Point it at an image or a directory and let it do the repetitive part.

Full usage and options ↗
PowerShellCLI examples
# Extract one screenshotinlay screenshot.png
# Process a folder and its subfoldersinlay .\screenshots --recursive --out .\extracted
# Save a diagnostic preview and JSON reportinlay screenshot.png --preview --report
# Specify an exact crop in source pixelsinlay screenshot.png --rect 26,592,869,867
03 / By design

Your images
stay yours.

✓

Local processing. Images are processed on your machine. Inlay does not upload them or make network requests.

✓

Original dimensions. Extracted images are not resized.

✓

Careful with uncertainty. Review and rejected detections are not exported as extracted images.

Early developmentv0.1.0

Useful already.
Still being validated.

The first detector is a classical computer-vision baseline. Its confidence score is a heuristic ranking, not a calibrated probability. Accuracy targets will only be claimed after testing against a labelled screenshot dataset.
